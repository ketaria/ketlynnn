
# Projeto de Modelagem Preditiva com Python

## Descrição

Projeto desenvolvido para estudar matemática, estatística e
programação utilizando Python.

O objetivo é construir um modelo matemático capaz de representar
o tempo de sono de uma população por meio de uma distribuição
normal (gaussiana).

Também estudamos como os modelos matemáticos podem ajudar
a prever situações reais e quais são suas limitações.

## Objetivos

- Trabalhar com dados reais.
- Calcular média e desvio padrão.
- Criar distribuições normais.
- Simular até 100 mil pessoas.
- Comparar amostras diferentes.
- Validar modelos matemáticos.
- Entender fenômenos previsíveis e imprevisíveis.
- Analisar as limitações das previsões.

## Tecnologias utilizadas

- Python
- NumPy
- Matplotlib
- Google Colab

## Conceitos estudados

### 1. Modelagem matemática

É a utilização da matemática para representar situações
e fenômenos do mundo real.

### 2. Distribuição normal

É uma distribuição estatística em que os valores tendem
a se concentrar ao redor da média.

### 3. Média

Representa o valor central dos dados.

### 4. Desvio padrão

Indica a dispersão dos valores em relação à média.

### 5. Validação

Consiste em comparar as previsões do modelo com novos dados
para verificar se ele apresenta resultados adequados.

## Fenômenos e previsibilidade

### Fenômenos mais fáceis de prever

- Estatura média da população.
- Tempo habitual de deslocamento.
- Comportamentos que apresentam padrões estáveis.

### Fenômenos difíceis de prever

- Preço do dólar no dia seguinte.
- Música que ficará viral na internet.
- Acontecimentos inesperados.
- Situações que mudam rapidamente.

## Por que alguns modelos falham?

Todo modelo matemático é uma aproximação da realidade.

Alguns fenômenos dependem de muitas variáveis que podem mudar
rapidamente. Por isso, mesmo modelos bem construídos podem
apresentar erros.

## Conclusão

Durante o projeto, aprendemos que a matemática e a programação
podem ser utilizadas para analisar dados e construir modelos
capazes de representar situações reais.

Também entendemos que nem todos os fenômenos podem ser previstos
com facilidade.

Fenômenos estáveis geralmente apresentam padrões mais previsíveis,
enquanto fenômenos voláteis podem mudar rapidamente.

Por isso, todo modelo precisa ser comparado com dados reais
e validado antes de ser utilizado para fazer previsões.
